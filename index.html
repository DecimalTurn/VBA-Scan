  • XLAM: Excel Macro-Enabled Add-In
  • DOCM: Word Macro-Enabled Document
  • DOTM: Word Macro-Enabled Template
  • PPTM: PowerPoint Macro-Enabled Presentation
  • POTM: PowerPoint Macro-Enabled Template
  • PPSM: PowerPoint Macro-Enabled Show

How it works

Python runs in this page using Pyodide, a WebAssembly runtime. The page passes your selected document to oletools in the browser, where it checks for VBA and Excel 4.0 macros, stomping, and suspicious indicators. Macros are analyzed as data and are not executed.

Because the analysis runs on your device, a server does not need to receive the document. On first use, your browser downloads Pyodide and oletools; those are analysis-engine files, not your document. The document is read locally and removed from the runtime's temporary filesystem after analysis.
